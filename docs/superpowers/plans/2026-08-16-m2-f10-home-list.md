# M2 F-10 Home List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete SCR-A02 three-tab, paged home list while leaving SCR-A05 for the next project.

**Architecture:** A dedicated JWT-protected `promise-home-list` Edge Function calls one service-role-only `lf_promise_home_list` RPC. The server owns participation, tab membership, ordering, pinned exclusion, counts, and stable cursors; the app owns independent per-tab caches and refresh/page generation fencing.

**Tech Stack:** TypeScript, Vitest, PGlite/PostgreSQL, Supabase Edge Functions, React Native, Expo Router, jest-expo.

## Global Constraints

- Execute every behavior as RED, observed expected failure, minimum GREEN, focused regression, then refactor.
- Page size is exactly `PROMISE_HOME_PAGE_SIZE = 20`; callers cannot override it.
- Pinned promises appear only on ACTIVE and never duplicate ordinary items.
- All product strings live in `SCR_A02_LABEL`; all visual values use mobile tokens.
- DRAFT → SCR-A03, PENDING → SCR-A04, CHECKING → SCR-A06; other cards are read-only.
- No advertisement or reserved advertisement space.
- Do not modify or commit `.claude/settings.local.json`.
- Do not run `supabase config push` or claim remote completion while Management API 403 remains.
