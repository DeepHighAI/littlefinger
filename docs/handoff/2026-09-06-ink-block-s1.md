## Decisions made + why

- PO E1–E6 (plan §2): all five handoff items approved; A00/A01 keep layout and accept token drift;
  Pretendard 500/900 downloaded from the v1.3.9 release (same Version 1.309 / 14716 glyphs as the
  existing files); full app + web scope; `CANCELED` = muted + `remove`; uncovered screens are
  extrapolated then confirmed in the gallery.
- Routine: `--lf-press-offset: 3px` added so the press translate is a token (180 tokens, not the
  handoff's 179); icon subset weight 400 → 500 to match the guide's `@import`; hard shadows use
  RN New-Architecture `boxShadow` (Android `elevation` cannot draw a blur-free ink offset).
- Test moves, all deliberate: token count 180; weights 500/600/800/900 (typed with `satisfies`
  against `TextFontWeight`); elevation parity now parses the CSS `box-shadow` values; the
  `textSecondary / primaryContainer` pair was removed because the new yellow gives 4.03:1 and the
  guide forbids secondary text on the four faces; the focus-ring 3:1 pairs are limited to canvas,
  paper, muted and yellow, and the three saturated faces assert the ink block shadow instead
  (mint 2.80 · pink 1.96 · sky 2.38 would fail). Record both as deviations in ADR 0020.
