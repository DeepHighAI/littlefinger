## Decisions made + why

- **Ovals are SVG paths**, not `borderRadius`: RN cannot draw elliptical corners; the CSS radius-scaling rule is
  implemented in `ovalPath`, the 5px shadow is the same path offset (so `overflow: hidden` never clips it).
- **Press feedback = literals** `translate(3,3)` + shadow `2px` (5px faces) / none (3px faces); disabled = no shadow.
  Google 52h, compact 44h, trailing icon 22, segmented 38, avatar md 44, badge 24, notice 32, wizard 8, caption
  line 19, stamp 22/18, blob 240×211, loop scale .5, eyes 60/80, `#FFE59A` + `-2deg` — all ADR 0020 exceptions.
- **48dp via hitSlop** for tonal 36, compact 44, segmented 38, menu button 40 — mirrors the gallery `::after`.
- **Kakao in RN = 5px** (only A01 uses it; README login variant). Chip `LfText` variant = 12 (`.lf-chip` uses meta).
- COMPLETED stamp time uses the `chip` variant (12/800 ink) for the CSS 12.5/800 — no 12.5/800 variant exists.
- `LfBlob.tilt` kept as a typed no-op so frozen routes compile; remove in P6 with the `login` → `LfOval` swap on A01.
- Home menu counts come from `listNotificationInbox({}).unread_count` and `loadSlotStatus()`; failures leave null and
  never block the menu. The slots tile routes to `/profile` (no slot screen exists).
