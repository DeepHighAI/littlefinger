## Decisions made + why

- PO E1–E6 (plan §2). Routine calls: press offset and pressed shadows are tokens, not literals;
  icon subset weight 500; RN hard shadows via New-Architecture `boxShadow`.
- P3 transitional choices (all resolved by P4 markup): `.lf-status-dot`, `.lf-chip--cream`,
  `.lf-avatar-button` and the legacy `.lf-pinky*`/`.sl-*` block stay in CSS until the last HTML
  consumer is rewritten; the old hero blob is hidden with `display: none`; unselected tabs/chips use
  weight 600 because the guide's "700" does not exist in the 500/600/800/900 scale; the base avatar
  maps to `--lf-avatar-lg` (48) because there is no 44 token; the filled CTA label uses
  `--lf-type-appbar-size` (16) because that is the only 16 step in the scale.
- Deviations to record in ADR 0020: secondary text never sits on the four faces (yellow 4.03:1);
  focus on mint/pink/sky is the ink 3px block shadow (outline 2.80/1.96/2.38 fails 3:1).
