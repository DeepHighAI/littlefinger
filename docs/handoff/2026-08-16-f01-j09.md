# Decisions and Rationale

- Legal documents remain visibly marked non-deployable drafts at version `2026-08-16-draft.1`; unknown production facts remain explicit placeholders.
- New-user terms recording is part of the auth trigger transaction. The legacy exception-swallowing trigger behavior was removed because the approved invariant requires auth user, public user, and agreement to succeed or roll back together.
- Legacy provisioning records the current versions only when no agreement history exists; it never infers consent to a later version.
- J-09 incidents are private and never user notifications. `hash_verified_at` records the completed check time only.
- J-09 treats the latest activated version as authoritative so a corrupted `current_version_id` pointer is detectable. It stores hashes and field names, never raw promise content, and never repairs source records.
- `integrity_incidents` has one lifecycle per promise/version/kind and a foreign-key index for version cleanup. Client roles have no table or function privileges.
